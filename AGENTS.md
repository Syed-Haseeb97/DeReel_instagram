# DeReel

DeReel is an Android utility built around an embedded Instagram WebView.

## Build and verify

- Debug APK: `./gradlew assembleDebug`
- Tests: `./gradlew testDebugUnitTest`
- Lint: `./gradlew lintDebug`

Read `SPEC.md` before coding if it exists. Keep Android namespace and application ID as `com.example.dmsonly`. Name feature branches `feature/<slice>`.
